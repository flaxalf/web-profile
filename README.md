# Portfolio

This portfolio is built with **Next.js** and a library called [Nextra](https://nextra.vercel.app/). It allows you to write Markdown and focus on the _content_ of your portfolio.

## How to use locally or on Vercel

Execute locally:

```bash
pnpm dev
# or
npm run dev
```
Execute on Cloud:

Deploy with [Vercel](https://vercel.com/) ([Documentation](https://nextjs.org/docs/deployment)).
